## 📌 Overview

Money Damage Checker Rupiah App is an Android application project developed to explore the analysis of Indonesian Rupiah banknotes using image processing and machine learning technologies.

The project combines Android development with computer vision tools to process and analyze banknote images.

## 🛠️ Technologies Used

- **Java** — Android application development
- **Android SDK** — Android development tools
- **OpenCV** — Image processing and computer vision
- **TensorFlow Lite** — Machine learning model integration

## ✨ Project Highlights

- Android application development using Java
- Image processing with OpenCV
- Integration of TensorFlow Lite models
- Practical exploration of computer vision and machine learning

## 🚀 Getting Started

### Prerequisites

- Android Studio
- Android SDK
- Git

### Installation

1. Clone this repository:

   ```bash
   git clone https://github.com/WorkFly-cloud/Money-Damage-Checker-Rupiah-App.git
   ```

2. Open Android Studio.
3. Select **Open** and choose the cloned project directory.
4. Allow Gradle to sync and download the required dependencies.
5. Build and run the application on a compatible Android device or emulator.

Additional configuration may be required depending on your development environment.
